Função

O que é uma função?

Uma função é uma relação entre dois conjuntos em que cada valor de entrada está relacionado a um único valor de saída. Ela é muito utilizada para representar relações entre diferentes grandezas.
Em uma função, temos um valor de entrada, chamado de x, e um valor de saída, geralmente representado por f(x).

Exemplo:

f(x) = 2x + 3

Isso significa que, para descobrir o valor de f(x), devemos substituir o x pelo valor desejado e realizar os cálculos.


Calculando uma função

Para calcular o valor de uma função, basta substituir a incógnita pelo número informado.

Exemplo:

f(x) = 2x + 3

Para x = 4:

f(4) = 2(4) + 3

f(4) = 8 + 3

f(4) = 11


Função do 1º grau

A função do 1º grau possui a forma:

f(x) = ax + b

Nessa expressão, a e b são números reais e a deve ser diferente de zero.

Exemplo:

f(x) = 3x + 2

Para x = 5:

f(5) = 3(5) + 2

f(5) = 15 + 2

f(5) = 17


Domínio e imagem

O domínio é o conjunto de valores que podem ser utilizados como entrada da função.

A imagem é o conjunto dos valores obtidos como resultado da função.

Exemplo:

f(x) = x + 2

Se x = 1, temos f(1) = 3. Portanto, 1 é um valor de entrada e 3 é o valor correspondente de saída.


Gráfico de uma função

Uma função também pode ser representada por meio de um gráfico. Em uma função do 1º grau, o gráfico é uma reta.

Os valores de x ficam no eixo horizontal e os valores de f(x) ficam no eixo vertical.


Dica do NOX: Sempre que aparecer f(x), pense que você precisa descobrir o resultado da função para determinado valor de x.
