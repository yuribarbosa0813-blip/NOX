Relações Binárias

O que é uma Relação Binária?

Uma relação binária é uma forma de relacionar elementos de dois conjuntos.

Ela indica quais elementos possuem uma determinada relação entre si.

Se temos dois conjuntos A e B, uma relação binária pode ser representada por pares ordenados:

R ⊆ A × B

Isso significa que a relação R é um subconjunto do produto cartesiano entre A e B.


Produto Cartesiano

Antes de entender completamente a relação binária, precisamos entender o produto cartesiano.

Considere:

A = {1, 2, 3}
B = {a, b}

O produto cartesiano A × B será formado por todos os pares possíveis:

A × B = {(1,a), (1,b), (2,a), (2,b), (3,a), (3,b)}

Uma relação binária pode escolher apenas alguns desses pares.


Exemplo Visual

Imagine dois conjuntos:

A

{1, 2, 3}

→

B

{a, b}

Podemos criar uma relação R selecionando alguns pares:

  • (1, a)
  • (2, b)
  • (3, a)
Dica do Nox:
Nem todo par do produto cartesiano precisa fazer parte da relação. A relação escolhe quais pares realmente possuem a característica que estamos estudando.

Exemplos de Relação Binária

Exemplo 1 — Relação "menor que"

Considere o conjunto:

A = {1, 2, 3}

Podemos criar uma relação onde um número se relaciona com outro quando ele é menor que o segundo.

R = {(1,2), (1,3), (2,3)}
Como interpretar?

(1,2) significa que 1 é menor que 2.

(1,3) significa que 1 é menor que 3.

(2,3) significa que 2 é menor que 3.

Exemplo 2 — Relação "maior que"

A = {1, 2, 3}

R = {(2,1), (3,1), (3,2)}

Aqui temos pares onde o primeiro elemento é maior que o segundo.

Exemplo 3 — Relação de igualdade

A = {1, 2, 3}

R = {(1,1), (2,2), (3,3)}

Cada elemento está relacionado com ele mesmo.

Propriedades das Relações

Algumas relações possuem propriedades importantes. As principais são:

1. Reflexiva

Uma relação é reflexiva quando todo elemento está relacionado consigo mesmo.

Para todo x ∈ A → (x,x) ∈ R
Exemplo:

A = {1, 2, 3}

R = {(1,1), (2,2), (3,3)}

Todos os elementos aparecem relacionados com eles mesmos. Portanto, a relação é reflexiva.

2. Simétrica

Uma relação é simétrica quando, se um elemento se relaciona com outro, o contrário também acontece.

Se (a,b) ∈ R → (b,a) ∈ R
Exemplo:

R = {(1,2), (2,1)}

Como existem os dois pares, a relação é simétrica.

3. Antissimétrica

Uma relação é antissimétrica quando dois elementos diferentes não podem estar relacionados nos dois sentidos ao mesmo tempo.

Se (a,b) ∈ R e (b,a) ∈ R → a = b
Exemplo:

R = {(1,1), (2,2), (1,2)}

Não existe (2,1). Portanto, não há dois elementos diferentes relacionados nos dois sentidos.

4. Transitiva

Uma relação é transitiva quando, se um elemento se relaciona com um segundo e o segundo se relaciona com um terceiro, então o primeiro também se relaciona com o terceiro.

Se (a,b) ∈ R e (b,c) ∈ R → (a,c) ∈ R
Exemplo:

R = {(1,2), (2,3), (1,3)}

Como 1 se relaciona com 2 e 2 se relaciona com 3, também temos 1 relacionado com 3.
