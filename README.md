 🤖 NOX - Assistente de Matemática

O **NOX** é um site desenvolvido com o objetivo de auxiliar estudantes no aprendizado de conteúdos básicos de matemática.

O projeto apresenta explicações, exemplos e exercícios de forma simples e organizada, facilitando a compreensão dos conteúdos.

📚 Conteúdos

O NOX possui conteúdos relacionados a:

- Relação Binária
- Equações
- Funções
- Porcentagem
- Tabelas-Verdade

💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

🎯 Objetivo do projeto

O principal objetivo do NOX é criar uma ferramenta simples e acessível para auxiliar estudantes nos estudos de matemática, utilizando uma interface fácil de navegar e conteúdos organizados por tópicos.
